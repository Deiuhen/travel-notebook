# ✈ 出国旅行手账

多人实时协作的旅行规划页面，单个 `index.html`，无需服务器、无需注册。

- **清单 / 行程 / 想去 / 账本 / 随手记** 五个板块
- **行程地图**：所有地点按天着色、编号、连线，可拖动校准（OpenStreetMap，不需要 API Key）
- **Google Maps**：地点一键打开、每天按顺序生成导航路线，一键导出 KML 导入 Google My Maps
- **多币种 AA 记账**：一键联网更新汇率、改主币种自动换算、随手换算器、结算可切换任意币种显示，自动算出谁转给谁
- **实时同步**：邀请码派生密钥，内容在浏览器里 AES-GCM 加密后存到公共 Nostr 中继，按字段合并修改

在线使用：https://deiuhen.github.io/travel-notebook/
